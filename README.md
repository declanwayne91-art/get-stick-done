# Get St*ck Done! (alpha demo)

An ADHD-friendly life organiser where every win becomes a sticker in your own sticker book.

**Try it:** https://declanwayne91-art.github.io/get-stick-done/

This is the clickable alpha: every screen from the design, linked together and sized for a phone.
Progress (your name, plan, list and stickers) is saved in your own browser only. Use the **DEMO** button
at the top, then **reset demo**, to start again as a new user.

## What's here
- `index.html` is the demo shell: the app screen plus the DEMO menu (back, home, every screen, reset).
- One page per screen (`Today.html`, `StickerAlbum.html`, `PlanWeek.html` and so on), generated from the design canvas.
- `dc.js` is a small runtime that runs the design boards as ordinary web pages.

The real app will be built in this repository next, replacing the generated pages screen by screen.
